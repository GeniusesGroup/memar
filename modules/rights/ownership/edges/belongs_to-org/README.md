# Belongs to org

indicate quiddity belongs to which organization.
e.g. `product`(iphone 16 pro max) `belongs_to_org` `org`(Apple)

## Model

- `(quiddity)-[:belongs_to_org]->(org)`

## Policies (rules)

- indicate labeling occur in which organization.
- It is better to be a automatic process not human base one.

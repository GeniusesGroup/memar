# Computer code

## Model

- `(contract)-[:computer_code]->(rule)`

## Policies (rules)

- Many contract factors must set in computer code to check by automated processes.
- e.g. Mass, Density, WeeklyRent, MonthlyRent, DueTo, ...
- The bare name code is not this edge. It can also mean the human-language sentence. This edge is the machine-checkable form.
- [Law](../../law/edges/computer_code/computer_code.md) uses the same name for a law's machine-checkable form. Whether the two are one shared edge is still open. The name is not.

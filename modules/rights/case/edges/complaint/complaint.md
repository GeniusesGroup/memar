# Complaint
A complaint (shekvaieh) is a claim-type label that groups claim types, together with the text explanation a type already carries. It is not a node and not an edge. The registered word is [complaint](../../../../../modules-plugable/rights/claims/labels/complaint/complaint.md).

## Model
- No complaint node. No edge type named `complaint`.
- The label groups claim types. Attachment stays the label domain's `(thing)-[:label]`. This file does not add a second mechanism.
- The [case](../../case.md) stays the dispute node. A petition stays an ordered path of cases ([petition](../petition/petition.md)).

## Policies (rules)
- Typed categories, on the 2026-09-27 input, are a paper-era aid. An agent can derive a claim from a conversation. The tag stays because that recognition already exists.
- One case still invokes one [claim service](../service/service.md). A second service is a second case.
- The users on a case are the ends of [plaintiff](../plaintiff/plaintiff.md) and [defendant](../defendant/defendant.md). The tag does not carry those users.
- [Kidnap](../../../../../modules-plugable/rights/claims/edges/kidnap/kidnap.md), [stolen](../../../../../modules-plugable/rights/claims/edges/stolen/stolen.md), and [illegal](../../../../../modules-plugable/rights/claims/edges/illegal/illegal.md) stay kinds of dispute. This file does not retire them and does not redraw them.

## Placement
- **Not an edge.** The registered word is the claim-label folder linked above. [Complaint-url](../complaint-url/complaint-url.md) stays an intake sketch already refused as an edge.
- **Nearest alternative rejected:** a complaint node beside the case. The ratified job is grouping claim types, which a tag does, plus the explanation the type already has.
- **Nearest alternative rejected:** calling the case node the complaint. The case is the dispute. The complaint is the grouping tag.
- **Not a kind under** [claims](../../../../../modules-plugable/rights/claims/claims.md). Kinds are optional accusations. A complaint groups claim types. It is not itself one accusation edge.
- **The folder** is [claim labels](../../../../../modules-plugable/rights/claims/labels/labels.md), on the pattern of law labels.
- What would falsify the placement of the grouping in a label and not in the graph: a complaint node, or a complaint edge, as the grouping of claim types. Model v4 point 14. The label folder above is where the grouping lives.

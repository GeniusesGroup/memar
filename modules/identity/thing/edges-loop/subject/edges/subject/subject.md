# Subject

## Model

- `(thing)-[:subjective]->(---)`

## Policies (rules)

- Thing MUST get just `object` or `subject` tag not both in one time.
- e.g. `Persia country` is a subjective label for the thing.
- e.g. `Bus route #73` is a subjective label for the thing.
- If this label not relate to a thing, It means thing is `object`
- e.g. `Dena mountain` is a object label for the thing.

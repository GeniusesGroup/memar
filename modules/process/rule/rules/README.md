# Rule Rules (`modules/process/rule/rules/`)
Rules for the conditions a Rule is held to. The general Memar concept of Rule is defined in [`rule.md`](../rule.md); a Rule is held by the module that owns its subject ([Which Module a Rule Belongs To](../rule.md#which-module-a-rule-belongs-to)).

| Rule | Subject | Tier | What it is |
| --- | --- | --- | --- |
| [A Rule Is Code Where It Can Be](./rule-is-code/rule-is-code.md) | How far a rule's condition is code | Governance | The condition is a check or declaration in Khayyam wherever a program can decide it; the text keeps the reasons |

The Rule is governance-tier and is enforced by no check this repository runs today; an organization adopting this repository's Rules may keep, relax, or replace it without forking anything.

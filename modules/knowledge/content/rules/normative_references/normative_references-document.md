# Normative References — Document
A document whose content is settled is still written to Memar's written surface, routed by what it holds, and named by its structure, so it reads these.

- [Documentation → Written surface](../../../../../modules-plugable/knowledge/documentation/documentation.md#written-surface) — the surface rules every edit applies, such as no blank line under a title and never two blank lines in a row. `reviewed 6597c04969bb`
- [Documentation Rule — A Rejected Position Leaves the Body → The rule](../../../../../modules-plugable/knowledge/documentation/rules/rejected-position-leaves-the-body/rejected-position-leaves-the-body.md#the-rule) — a position the owner rejected is deleted, not annotated, and its examined alternative gets one home. `reviewed a78b24dac0e2`
- [Documentation → Results routing](../../../../../modules-plugable/knowledge/documentation/documentation.md#results-routing) — each durable result is routed by its type, never into a side note. `reviewed bd69ca6bbe65`
- [Documentation Rule — No Derivative Inventory → The rule](../../../../../modules-plugable/knowledge/documentation/rules/no-derivative-inventory/no-derivative-inventory.md#the-rule) — no membership index of a collection is written, and no document set the task does not need is enumerated. `reviewed 2c7fa45f5a19`
- [Documentation Rule — A README Is a Link to the Main Document → The rule](../../../../../modules-plugable/knowledge/documentation/rules/readme-is-a-link-to-the-main-document/readme-is-a-link-to-the-main-document.md#the-rule) — a folder with a main document takes its README as a link to it; one without keeps a real README. `reviewed d480be98892e`
- [Documentation → File Naming](../../../../../modules-plugable/knowledge/documentation/documentation.md#file-naming) — what each separator in a file name carries: the category, the topic, and the facet. `reviewed 8994641ad77c`

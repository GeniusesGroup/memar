# Cognition Rule — Run Debriefing
A rule held for [Cognition](../../cognition.md), for learning from a completed run.

## The rule
- **Attribute an outcome before recommending a change.** Separate plan design, execution, tool or environment, and goal causes.
- **Treat one run as one result, not as a recurring pattern.** Recommend only the smallest change its evidence supports.
- **Base the debrief on the run report:** what ran, the check applied, the boundary, and the stopping reason.

## Why it exists
Without an attributable, bounded record, a debrief is opinion rather than an evaluation of cognitive material.

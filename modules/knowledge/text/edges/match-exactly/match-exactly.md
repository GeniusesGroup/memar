# Text match exactly

## Model

- `(text)-[:match_exactly]->(text)`

## Policies (rules)

- It means first text is same as second text e.g. `omidhekayati` is appear in `omidhekayati` text.
- Usually first one is a query and second one is actual text.
- It is just in logic layer and in GUI use in very rare case, even in username matching apps just show exact match in first and show other matches too.

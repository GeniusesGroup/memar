# Modeling Rule — Classification Readiness
A rule held for [Modeling](../../modeling.md), for detecting a classification made before its rules justify it.

## The rule
- **Do not resolve agreement on behavior and relationships by arguing about a label.** State the definition first.
- **Do not retain a category hierarchy whose members were not derived from observed shared properties.**
- **When a classification needs invented caveats, a third category for cases between two, or a different label in each context, examine whether it is a role, a relation, or a continuum instead.**
- **Promote a classification only when it completes the rule-and-relation sentence that [Modeling](../../modeling.md) requires.**

## Why it exists
A label applied before the rules and relations that support it hides an unfinished model behind a name.

# Question status

## Model

- Candidate (unconfirmed): question record statuses — waiting-for-approval, Terminated, Deprecate.

## Policies (rules)

- Proposed names: waiting-for-approval, Terminated, Deprecate. No transition rule is recorded.

## Placement

- These names are question-record statuses.
- A status is a Status-kind [label](../../../label/label.md); a domain's own statuses are declared on that domain.

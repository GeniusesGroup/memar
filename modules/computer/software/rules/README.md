# Software Rules (`modules/computer/software/rules/`)
Rules for the conditions software developed in this repository is held to. The general Memar concept of Rule is defined in [`modules/process/rule/rule.md`](../../../process/rule/rule.md); a Rule is held by the module that owns its subject ([Rule → Which Module a Rule Belongs To](../../../process/rule/rule.md#which-module-a-rule-belongs-to)).

| Rule | Subject | Tier | What it is |
| --- | --- | --- | --- |
| [Abstraction First](./abstraction-first/abstraction-first.md) | The order in which a software requirement is developed | Governance | The abstraction in Khayyam, approved, before any code of it |

The Rule is governance-tier and is enforced by no check this repository runs today; an organization adopting this repository's Rules may keep, relax, or replace it without forking anything.

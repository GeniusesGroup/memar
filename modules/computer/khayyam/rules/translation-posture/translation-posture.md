# Khayyam Rule — Translation Posture
A rule held for [Khayyam](../../khayyam.md), applying when existing code is translated into Khayyam.

## The rule
- **Translate structure for structure when Khayyam is requested as a mechanical target.** Map the source construct to the corresponding language construct without pressing a redesign, renaming, or re-decomposition that the request did not ask for.
- **Apply full design treatment only when the request asks for Khayyam written as Memar intends.**
- **When the requested posture is unclear, begin with mechanical translation and make the fuller pass available.**

## Why it exists
Translation and domain redesign serve different ends; treating a requested port as a redesign silently changes the work being delivered.

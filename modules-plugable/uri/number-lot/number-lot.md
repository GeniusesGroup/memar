# LOT
A [lot number](https://en.wikipedia.org/wiki/Lot_number) is an identification number assigned to a particular quantity or lot of material from a single manufacturer.
Lots correspond to a certain number of products you received and store altogether in one single pack.

## LOT vs Batch

A Lot Number is a broader term that can encompass multiple batches. It refers to a group of products that are manufactured under similar conditions, using the same recipe and raw materials, but may span across different production runs.

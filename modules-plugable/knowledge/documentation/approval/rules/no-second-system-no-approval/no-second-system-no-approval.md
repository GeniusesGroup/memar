# Approval Rule — No Second System, No Approval
A rule of this repository, held for [Approval](../../approval.md), which owns the claim in [Approval Requires a Reviewer Who Did Not Do the Work](../../approval.md#approval-requires-a-reviewer-who-did-not-do-the-work). This rule states what counts as a reviewer.

## The rule
- **The reviewer is a second cognitive system, not a second pass by the first.** Re-reading one's own work carefully is not a review: it is the same reader with the same model, and it finds what it expected.
- **Independence from the work is required; a roster is not.** In this repository's practice the second system is a sub-agent given the four parts of [a review request](../review-request-has-four-parts/review-request-has-four-parts.md), because it starts without the task's context and so without the task's model of what the work meant.
- **Where a runtime offers no second system, no approval is placed.** The honest outcome is a content without an approval.

## Why it exists
An approval records that a second party checked. A first party writing it down says nothing a reader can use, and it hides that no second party was there.

## Keep it or drop it
An organization may let the maker approve small work. It then has two kinds of approval that read alike, and a reader must know which one it holds.

## What this rule does not claim
- It does not say that a person is not a second system; a person's approval is a content placed by that person ([Approval](../../approval.md#template)).
- It does not rank second systems by strength; [the model follows the need](../../../../../management/task/rules/model-follows-need/model-follows-need.md).

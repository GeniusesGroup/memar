# Explanation Rules (`modules-plugable/knowledge/documentation/explanation/rules/`)
Rules for what a body of an Explanation document holds. The general Memar concept of Rule is defined in [`modules/process/rule/rule.md`](../../../../../modules/process/rule/rule.md); a Rule is held by the module that owns its subject ([Rule → Which Module a Rule Belongs To](../../../../../modules/process/rule/rule.md#which-module-a-rule-belongs-to)), and the subject here is [Explanation](../explanation.md).

| Rule | Subject | Tier | What it is |
| --- | --- | --- | --- |
| [Framing Sections State the Subject, Not the Writing](./framing-sections-state-the-subject-not-the-writing/framing-sections-state-the-subject-not-the-writing.md) | The Abstract, Motivation and Methodology | Governance | Each sentence changes the reader's understanding of the subject, or it is dropped |
| [The Body Holds No Alternatives, Questions or Plans](./the-body-holds-no-alternatives-questions-or-plans/the-body-holds-no-alternatives-questions-or-plans.md) | What else a body must not hold | Governance | Each goes to the content of its kind on the task |

The Rules are governance-tier and are enforced by no check this repository runs today; an organization adopting this repository's Rules may keep, relax, or replace either without forking anything.

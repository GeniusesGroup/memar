# Comparison Rule — Self-definition Before Comparison
A rule of [Documentation — Comparison](../../comparison.md).

## The rule
- **An essay states the compared project's self-definition and judges it against that project's purpose before measuring it against the examining project.**

## Why it exists
Fair comparison begins from the work the other project claims to do, so difference of purpose does not become a defect by assertion.

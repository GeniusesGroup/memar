# Text (pluggable)
Mirror of kernel [Text](/modules/knowledge/text/text.md) ([Category Depth](/modules/knowledge/label/rules/category-depth/category-depth.md)): holds optional capabilities. Shared field types are declared in the kernel Text module.

## Capabilities
- [Likeness](likeness/likeness.md) — rank holders by kept label signatures (optional).
- [Retrieval](retrieval/retrieval.md) — find holders by label postings and field predicates (optional).

Shared roles both import from **kernel** Text: `Field_Text_Scope`, `Field_Text_Holder`, `Text_Holders`, `Field_TextID`.

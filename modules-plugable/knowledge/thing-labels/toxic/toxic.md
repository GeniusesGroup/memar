# Toxic
A label a person may attach to any node to mark the material as harmful.

## Abstract
Toxic is one word beside a comment. It can be attached to a text, a user, a product, or any other node. It does not change that node's type.

## Explanation

### Definition
The commenter means: they read the node as harmful to engage with.

The label does not remove the node. A detection rule may look for the word. The rule lives with detection, not here. [Sensitivity](../sensitivity/sensitivity.md) is a different word.

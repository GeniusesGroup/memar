# Modules, pluggable (`modules-plugable/`)
The optional capabilities of Memar's modules: each a module that attaches to a kernel module, or to another pluggable one, through an explicit relationship and can be removed whole. The placement, its test and its rules are [Modularity → Pluggable](../modules/knowledge/modularity/labels/pluggable.md); this place holds no document of its own about them. A pluggable module stands at `modules-plugable/<category>/<capability>/`, where the category is the one its kernel module has under [`modules/`](../modules/README.md), and its manifest, `<capability>.manifest.yaml`, carries its labels. A guest module — one whose subject is a surface Memar does not own — is a pluggable module labelled [`guest`](../modules/knowledge/modularity/labels/guest.md).

# Constitution
A comment label for a law the commenter treats as foundational.

## Abstract
Constitution is a word a person may attach beside a comment on a [law](../../../../../modules/rights/law/law.md). It is not a kind of law, not a rank, and not a harder path for change.

## Explanation

### Definition
The commenter means: this instrument is one they treat as foundational for the group that lives under it.

The instrument still opens, is signed, and changes as any other law: a change is a new node. The label does not block that change. It does not add a sentence, a goal, or a wish that the human code and the computer code do not already state. Anyone who comments may attach it. Registration writes the meaning. It does not appoint a founder as the only writer.

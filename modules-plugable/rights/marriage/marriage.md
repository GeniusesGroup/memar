# Marriage
An optional contract draft for the people who marry.

## Abstract
Marriage is a [contract](../../../modules/rights/contract/contract.md), as that type already records. This module is the draft a bundle can include on its own. Terms, including a marriage portion, are ordinary obligations of that contract.

## Introduction

### Motivation
The contract type already says marriage is a contract and that no new legal-relation entity is created per relationship kind. This module is the optional draft those parties adopt, separate from other household drafts.

## Explanation

### Definition
The parties adopt this draft, edit it, or pass it by. A bundle that does not offer marriage does not include the module. The clauses of the draft are added here when a founding writes them.

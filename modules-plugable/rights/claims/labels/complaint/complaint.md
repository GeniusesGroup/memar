# Complaint
A claim-type label that groups claim types.

## Abstract
Complaint (shekvaieh) is one word a person may attach as a [label](../../../../../modules/knowledge/label/label.md). It groups claim types, together with the text explanation a type already carries. It is not the [case](../../../../../modules/rights/case/case.md), and it is not an edge.

## Explanation

### Definition
The commenter means: these claim types are grouped under a complaint.

The label does not carry the parties, the votes, or the ruling. Those stay on the case. Typed categories, on the afternoon input, are a paper-era aid. An agent can derive a claim from a conversation. The label stays because a label is already recognized.

Registration writes this meaning. It does not choose which types a commenter groups. It does not weight a vote. It does not make civil a different adjudication model from criminal. Execution of either label is a compelled service whose input is not only a number.

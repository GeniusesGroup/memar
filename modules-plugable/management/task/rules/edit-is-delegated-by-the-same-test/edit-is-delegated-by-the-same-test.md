# Task Rule — An edit exempts no step, and forces none
Status: Draft

## The rule
An edit that carries out a decision already taken — code and its tests, a document change whose content is settled — is delegated by the same test as any step ([delegate by size of reading](../delegate-by-size-of-reading/delegate-by-size-of-reading.md)): a few files, or a reading under the marks, is done by the agent that holds the decision, and only a large edit, or one that reruns until clean, is delegated. An edit that is itself the decision stays local either way.

## Why it exists
Settled edits were once all delegated by name, which paid a new context for work the deciding agent could do from what it already held, and made it redo the fixes the reviewer then found.

## How a check would run
A delegated edit whose reading and writing were under the marks is a defect. Moved on 2026-10-26 from the Memar skill (task 20261026-T120341Z-16244); this repository runs no automatic check of it today.

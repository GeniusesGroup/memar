# Task Rule — A Task is not limited to code or to AI workers
Status: Draft

## The rule
A Task is any declared intent of a unit of work. The model must serve a user's complaint against the organization, the building of an inner partition wall on the second floor and a change to a source file alike, and must hold with no AI model and with no code anywhere.

## Why it exists
A model fitted to one kind of worker or work breaks on the others and drifts toward that worker's tools.

## How a check would run
Read the Task domain's documents for a field, relation or example that holds only for software or for an AI worker; each is a defect. The statement is the owner's, recorded in [the Task handoff](../../../../../modules/management/task/task.handoff.md#owners-rulings-the-second-round-2026-10-18); this repository runs no automatic check of it today.

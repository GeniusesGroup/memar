# Task Rule — A Chat Commits Only the Files It Changed
A rule of this repository for a tree that several chats work in. The statement is the owner's, 2026-10-16.

## The rule
- **A chat commits only the files it changed,** with the small earlier changes already in those files. The work of other chats in the same tree is theirs to commit.
- **A folder the owner says two chats are working in is left to them.**
- **A small touch,** such as one repaired link in a file the commit is not about, waits for a later commit and does not widen this one.

## Why it exists
A commit that carries another chat's half-made files puts unfinished work in the history under the wrong name, and cannot be reviewed as one change.

## Keep it or drop it
An organization with one chat in one tree needs none of it.

## What this rule does not claim
- It does not decide which chat owns a file; the status of the tree and the chat's own record of what it changed do.
- This repository runs no check of it today.

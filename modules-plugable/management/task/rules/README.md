# Task rules
One folder per rule; each cites where the owner's word is recorded and may be changed at any time.

| Rule | What it is |
| --- | --- |
| [A Tangent Is Recorded at Once, Not Followed](./a-tangent-is-recorded-at-once/a-tangent-is-recorded-at-once.md) | A request the task will not need is recorded at once for a task of its own |
| [Another Task's Work Is Corrected Only After It Ends, and the Correction Is Reported](./correct-another-tasks-work-only-after-it-ends/correct-another-tasks-work-only-after-it-ends.md) | Correct only a finished task's work, and report it |
| [A Commit Needs the Owner's Word, and a Small Commit Needs No Task](./commit-needs-the-owners-word/commit-needs-the-owners-word.md) | Permission, timing, and no task for a commit |

| [Old Task Folders Are Swept by the Owner's Ruling](./old-task-folders-are-swept-by-ruling/old-task-folders-are-swept-by-ruling.md) | What becomes of a folder the daily sweep leaves |

| [The Owner Gets One Digest, Not a Question per Task](./the-owner-gets-one-digest/the-owner-gets-one-digest.md) | One list of decisions at the end |

# Task Rule — A Task Is for Work
A rule of this repository for what may be a task of its own. The statement is the owner's, 2026-10-22.

## The rule
- **A task's check is that something was done:** a change applied, or a decision recorded where it governs.
- **A task whose check is a finding, a survey or a proposal for approval is a step of the task of the work it improves,** never a task of its own. It is written into that plan as a step, the finding revises the plan, and the task stays Active, or Blocked while it waits for a ruling. A task that only proposed is not Complete.
- **An inquiry,** looking into Memar or the work to answer the task's own questions, **is a step of the task it serves,** and what it finds is a content of that task ([a task has no docs folder](../a-task-has-no-docs-folder/a-task-has-no-docs-folder.md)).
- **A research that gathers and concludes what many other tasks will build on** is a task of its own, recorded as a [Research](../../../../knowledge/documentation/research/research.md) document. An investigation that no work waits on and that is no such research is a [question of the task](../a-question-belongs-to-a-task/a-question-belongs-to-a-task.md) it came from.
- **A new task is opened only for work that is truly independent.**

## Why it exists
A finished-looking task for a proposal is archived, swept and forgotten while the work it was for was never done.

## Keep it or drop it
An organization may open a task for each study, and then keeps a store of findings that no plan owns.

## What this rule does not claim
- It does not forbid the study: the study is a step.
- This repository runs no check of it today.

# Task Rule — A chat opened for a task whose result is not needed is left alone
Status: Draft

## The rule
Once a chat is open for a task whose result the opening chat does not need, read nothing from it, poll it for nothing, and do not follow it up or ask it for news. The owner answers its questions there, and a task that needs its outcome reads its report.

## Why it exists
Each look spends the opening chat's context for nothing.

## How a check would run
A task's chat that reads, polls or asks a chat it opened for an independent task breaks the rule. Moved on 2026-10-26 from the Memar skill (task 20261026-T120341Z-16244); this repository runs no automatic check of it today.

# Task Rule — A new person is a participant unless the ask is a Task of its own
Status: Draft

## The rule
Asking someone for an opinion makes a child Task only if the ask needs its own done-or-not-done state, its own person who accepts or declines it, or its own check. Otherwise the person joins the same Task as a participant. An opinion that must not see another opinion is hidden by what each participant may see, or is a Task of its own.

## Why it exists
Many consultations are one answer in a discussion; making each a Task fills the graph without carrying anything. This rule may be amended at any time.

## How a check would run
For a given ask, answer the three questions; one yes makes a Task. The statement is the owner's, recorded in [the Task handoff](../../../../../modules/management/task/task.handoff.md#owners-answers-to-the-six-questions-2026-10-18); this repository runs no automatic check of it today.

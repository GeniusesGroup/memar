# Task Rule — The task's plan is not the runtime's to-do list
Status: Draft

## The rule
A runtime's to-do list or plan mode is not the task's plan: it ends with the context; the plan outlives it. Intake binds before work ([Cognition Practice → Norm Application Points](../../../../../docs/cognition.practice.md#norm-application-points)) and ends in the written plan, made before reading the material the work is about. Each step in it is decided local or delegated by [the size test](../delegate-by-size-of-reading/delegate-by-size-of-reading.md); a step the plan did not foresee takes the same test before it starts.

## Why it exists
Only what is written in the plan reaches the agent that continues the work.

## How a check would run
A task whose work is tracked only in a runtime's list has no plan. Moved on 2026-10-26 from the Memar skill (task 20261026-T120341Z-16244); this repository runs no automatic check of it today.

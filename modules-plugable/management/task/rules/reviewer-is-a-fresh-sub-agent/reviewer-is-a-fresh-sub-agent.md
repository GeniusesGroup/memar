# Task Rule — A reviewer has not seen the work
Status: Draft

## The rule
A reviewer is a newly started sub-agent that has not seen the work — never the agent that made it, nor a sub-agent resumed from the work. Its model follows [the model rule](../model-follows-need/model-follows-need.md).

## Why it exists
A reviewer that shares the maker's context shares its blind spots.

## How a check would run
The reviewer's task is a new one and its context holds none of the work's chat. Moved on 2026-10-26 from the Memar skill (task 20261026-T120341Z-16244); this repository runs no automatic check of it today.

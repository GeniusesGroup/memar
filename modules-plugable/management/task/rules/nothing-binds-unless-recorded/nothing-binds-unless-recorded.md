# Task Rule — Nothing binds unless it is recorded
Status: Draft

## The rule
What binds a Task or its readers is written as a decision, a question, a change or a reply. A reasoning that stays only in a participant's thinking text binds no one, and no one is bound to read it.

## Why it exists
A reader who skips thinking text must not be misled by an unrecorded decision. Memar's Cognition already requires state that must outlive a participant to be externalized.

## How a check would run
A decision found only in thinking text is not a decision; the finder raises it as a question on the Task. The statement is the owner's, recorded in [the Task handoff](../../../../../modules/management/task/task.handoff.md#owners-rulings-the-second-round-2026-10-18); this repository runs no automatic check of it today.

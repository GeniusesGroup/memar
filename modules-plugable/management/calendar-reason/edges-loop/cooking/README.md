# cooking

Calendar record reason: an entry typed `cooking` on a calendar.

Each reason carries its own **Policy (rule)** placeholder: the rules that decide when this reason may be used, and by whom, are organization policy - not code.

**Note from the original comment**: usually a calendar is a `product`, but it can also be other ones like a `task` - the calendar node is multi-typed (see modules/identity/estate/topic and the multi-typing principle).

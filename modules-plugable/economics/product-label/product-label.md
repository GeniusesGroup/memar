# Product-kind labels

Classification of a product node (commodity, intermediate, final) is a pluggable capability, not a second `product` domain. The folder is named `product-label` so it does not mimic core `product`.

The `label-*` folders are self-classifications under `edges-loop/`. Storefront `products.html/js/css` live under `modules-plugable/economics/product/ui/page-products`.

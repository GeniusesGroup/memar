# Product-kind labels

Classification of a product node (commodity, intermediate, final) is a pluggable capability, not a second `product` domain. The folder is named `product-label` so it does not mimic core `product`.

The `label-*` folders are self-classifications and belong under `edges-loop/` in a later pass. Storefront `products.html/js/css` stay here only until GUI placement is decided; they are not this capability.

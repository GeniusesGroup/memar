- **Abstraction first — broken everywhere.** The three commits add no `.kh` file. Every abstraction of the output (the store contract, `lockable`, `record`, `view`, the adapters' capabilities) exists as Python or as Markdown; no approval record by a fresh agent precedes the code.

- **Models — broken.** All four sub-tasks ran on the strongest model (their reports say `opus`); the plans were not re-read for a line saying who checks, which the new rule asks for.
- **Hand-back — followed in fact, not by a rule.** The reports of all four sub-tasks were written by the delegating agent from the hand-back; only the report of 11720 says the harness refused the write; the others say only that the delegating agent wrote them.

# Memar preferences
This file is this project's own: `memar install` creates it when it is absent and never rewrites it, unlike the README beside it, which an install rewrites. The front matter holds what Memar's tools read. `sessions` is the folder new session folders are made in: a path relative to the project's top folder, or an absolute one, but neither that top folder itself nor a drive or filesystem root; left empty, they are made in Memar's own temp/sessions/. Memar's daily sweep never touches a session folder made in the `sessions` folder: keeping, committing, or deleting it is the project's. Below this paragraph, write any preference agents should follow on this project.

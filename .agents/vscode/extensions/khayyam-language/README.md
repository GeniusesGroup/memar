# Khayyam Extension for Visual Studio Code
Visual Studio Code is built with extensibility in mind. From the UI to the editing experience, almost every part of VS Code can be customized and enhanced through the [Extension API](https://code.visualstudio.com/api). In fact, many core features of VS Code are built as extensions and use the same Extension API.

Visual Studio Code provides smart editing features for different programming languages through [Language Extensions](https://code.visualstudio.com/api/language-extensions/overview). VS Code doesn't provide built-in language support in the core editor but offers a set of APIs that enable rich language features.

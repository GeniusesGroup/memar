# Normative References — Document
A document whose content is settled is still written to Memar's written surface, routed by what it holds, and named by its structure, so it reads these.

- [Documentation Practice → Written surface](../../../../modules/content/documentation/documentation.practice.md#written-surface) — the surface rules every edit applies, such as no blank line under a title and never two blank lines in a row. `reviewed f15bad04022f`
- [Documentation Practice → Rejected positions](../../../../modules/content/documentation/documentation.practice.md#rejected-positions) — a position the owner rejected is deleted, not annotated, and its examined alternative gets one home. `reviewed a17881137764`
- [Documentation Practice → Results and companions](../../../../modules/content/documentation/documentation.practice.md#results-and-companions) — each durable result is routed by its type, never into a side note. `reviewed c1c77b040116`
- [Documentation Practice → Creating or revising by facet](../../../../modules/content/documentation/documentation.practice.md#creating-or-revising-by-facet) — which practice a new or revised document of each facet follows. `reviewed 92df7c711d89`
- [Documentation Practice → Which file the doer reads](../../../../modules/content/documentation/documentation.practice.md#which-file-the-doer-reads) — the practice is followed, and its explanation opened only where a step names it. `reviewed 98ed9f85e4f7`
- [Documentation Practice → No derivative inventories](../../../../modules/content/documentation/documentation.practice.md#no-derivative-inventories) — no membership index of a collection is written, and no document set the task does not need is enumerated. `reviewed 7d8e3be7c942`
- [Documentation Practice → Folder READMEs](../../../../modules/content/documentation/documentation.practice.md#folder-readmes) — a folder with a main document takes its README as a link to it; one without keeps a real README. `reviewed 372d36645077`
- [Documentation → File Naming](../../../../modules/content/documentation/documentation.md#file-naming) — what each separator in a file name carries: the category, the topic, and the facet. `reviewed a36134561aed`

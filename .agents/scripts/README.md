# Scripts
Executable helpers for recurring host-tool work where Memar sessions need a constraint free-form shell habits keep violating. Each file documents itself via `--help`. This directory is **not** a pasteable command catalog and must not grow into one — if a need is not worth a small script with a stable interface, it does not belong here.

Harness apps often already own the same operations. Memar *documentation* navigation lives beside the Memar skill (`../skills/memar/scripts/`), not here. Discover what exists in this folder by listing it; do not maintain a membership index in this file ([documentation.md → Content Rule](../../docs/documentation.md#content-rule-no-fabricated-or-redundant-provenance)).

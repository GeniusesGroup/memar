# Khayyam examples
This folder holds the real examples of Khayyam: Khayyam files that a tool or a test reads or runs, such as a fixture the linter checks or a program the compiler builds. A document may refer to a file here instead of repeating it.

An illustrative example, one written only for a reader to see how something is used, stays in the document it illustrates and is not put here. What makes a fragment a real example is that a program takes it as a source, not its form. The rule is stated in [A Fact in Code Is Written Once](../../../modules/content/documentation/documentation.md#a-fact-in-code-is-written-once).

The folder is empty until the first real example arrives; the owner created it so that the place is not forgotten.

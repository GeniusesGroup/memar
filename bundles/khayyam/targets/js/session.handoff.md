# Session Handoff — Khayyam JavaScript Target and the repository around it
**This is not the JavaScript target's handoff.** That artifact is [`target.handoff.md`](./target.handoff.md), which carries this target's own open state. This file records **one working session that ran across the repository** — the Khayyam language documents, the protocol and model documents under `docs/`, three implementation modules under `modules/`, the rules catalogs under `bundles/`, and the framework documents under `docs/` itself — and exists so that session can be closed without losing what it left open. It is placed here only because this target's folder is where the session's decisive work sat; every item below names its own home and belongs wherever that home is. Nothing here is settled design, and nothing here has been graduated into a governing document.

This file was produced by reading the repository, not from any record of the session's conversation. Every claim below carries a `file:line` verified against the tree as it stands. Where a candidate item could not be confirmed, that is said rather than resolved. No item below has been fixed, closed, or decided — the owner is closing the session, not ruling on its contents.

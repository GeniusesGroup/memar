Khayyam in the browser

This page compiles a .kh program inside the browser with the JavaScript target's own compiler, loads what it emitted, and runs it (bundles/khayyam/targets/js/target.md → Compiling in a browser). The compiler is what npm run build:browser wrote under build/compiler/; this page builds nothing itself. Hand it every unit the program reaches, the root first, each with its URI. A unit is added from a file or as text, or by ?unit=URI in the address.

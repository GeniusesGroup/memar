## Status
Active — applied 2026-09-28 to the ported sources under `modules/` (excluding `bundles/khayyam/`): 826 blocks shrunk and 87 removed with their markers, 913 license headers, 704 members, and 262 whole types removed, in 911 files. ## Decisions
- **Remove only what the Khayyam file carries** — Decided (2026-09-28, owner). A Go method leaves only when its Khayyam method exists; the tests show it kept otherwise.
- **A Go comment is part of its declaration** — Tentative (2026-09-28, applied by the tool; awaiting the owner's review). A declaration whose comment the Khayyam file does not carry stays, so no prose of the reference is lost. Example: `SecondElapsed` in `modules/time/protocol/time.kh` stays because its trailing `// From Epoch` is not in the Khayyam file.
- **A sealed block is removed whole or not at all** — Decided (2026-09-28). The three sealed blocks under `modules/math/boolean/` keep their `sha256` valid.
- **A raw string spanning lines is counted by its lines** — Decided (2026-09-28). The first run over the sources counted a Go raw string as one line, removed three wrong lines from `modules/memory/record/services/service-{delete,wipe,write}-sdk.kh`, and was repaired: each file was rebuilt, the rebuild was proven by replaying the faulty run onto it, and the lexer and a test were corrected.
- **The blocks are committed with the sources, not withheld** — Decided (2026-10-01, owner). A commit boundary was proposed that stages only the `.kh` files carrying no block; it is rejected, because [`bundles/khayyam/core/tests/matrix.test.ts`](../../../../core/tests/matrix.test.ts) reads five block-bearing units as its `accept` rows (`computer/runtime/protocol/concurrency.kh`, `computer/capsule/protocol/life_cycle.kh`, `time/duration/nano-in-second.kh`, `net/srpc/protocol/srpc.kh`, `math/float/float-32.kh`) and further rows fail on transitive imports of block-bearing units, so that commit would enshrine a tree whose standing Test cannot pass. The block is the transfer's correspondence, not residue to be hidden from history. **What retires a block is unchanged and is this rule**: `tidy --rule go-clue-residue`, whose end state is zero blocks.

## Open Questions
- **Where the clue block's format is stated.** No governed document states the `// TODO(go-migrate):` block or its `* /` escape; the rule states the format it reads. The format's home is not decided. Committing the blocks raises what this decision costs: from 2026-10-01 the sources in version control are 815 files whose block is governed only by a rule document. The archived JavaScript blocks have the same gap with no rule at all — 851 blocks carry the bare marker and no source path, while 115 `// source: memar-js/<path>` lines name 102 distinct sources — so whether one decision governs both archive formats or two govern them separately is also undecided.
- **Where the transfer's own record lives.** This rule says a removed block does not mean a Go file is fully transferred, and that the ledger states that "from the Go source, not from the block" — so a block is not a transfer record and something else must be. Four units are known not to be fully carried, and nothing in the repository says so: `computer/adt/container/protocol/operations.go` is missing its two section titles, `CONTAINER LEVEL` and `ELEMENT LEVEL`; `process/error/protocol/optional.go` is missing the comment `// Who cause the error?`; `storage/record/protocol/gui-widget.go` is missing `// Open a dialog to choose attach files`; and `process/validators/_____sanitize.go` is a bare URL with no package clause, so the transfer dropped it whole. Whether those three comments and two titles are worth carrying, and whether the URL is recorded or written off, is the owner's; what is missing is any place to write the answer down. The retired Go repository is archived with a remote, so the source is recoverable and only the decision is not.

## Anticipated Work
Chartered 2026-10-05 from the Revision second-consumer walkthrough (contract holds; these two misfits are consumer gaps, not contract gaps). Both are per-target instantiations — the analyzer is named per target, never smuggled into the contract.
- **Pre-write plan artifact for `tidy --rule`.** Today `run_tidy` writes per-file inside the enumeration loop with no artifact a reader could review first. The plan (per-file ranges, what each becomes, why-skipped) must exist before any write, visible in dry output and `--report`. Acceptance: a dry run prints the full plan; `--write` produces byte-identical output to the plan applied; no write path bypasses the plan object.
- **All-or-nothing refuse gate.** Today one newly-broken file does not suppress writes elsewhere, and no analyzer judges the tree against found state. Compute the would-be tree, judge it with the language analyzer, and write nothing anywhere when one file would newly fail. Seal-integrity stays its own per-target check, not the gate. Acceptance: a run that would newly break file N writes zero files and reports N with the analyzer's verdict; seal handling unchanged.

## The transfer's record, measured
The transfer's own ledger was never committed — it lived in a working folder outside version control and was verified by a script that read it. Both are gone as of 2026-10-02, so what they established is written down here. This is the record's content, not a new claim, and it is what the open question above has no home for.
- **Every placed JavaScript source is in the sources byte for byte.** Re-run against the committed tree on 2026-10-02, after the sources were committed and after 99 files were given a final newline: 102 sources verbatim, 0 problems, across 32 destination files. The tool that established this is discarded; git now holds the blocks, and the blocks name their sources, so the record survives in the sources rather than beside it.
- **Twenty units of the Go reference were investigated for missing text; sixteen are closed.** Seven were `.md` files whose fate the documentation review decided, and nine were `.go` files later split into separate files, where the only absent lines are a package clause, an interface's shell, and members the port converted to `tp`. The four that remain open are the ones named above.
- **The Go reference is recoverable and the JavaScript reference is recoverable.** `memar-go` is archived with a remote at `GeniusesGroup/memar-go` and `memar-js` at archive commit `27e013d`, last pushed 2026-01-06. Neither ledger was the only copy of anything except its own bookkeeping.
